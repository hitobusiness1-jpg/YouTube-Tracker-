Мои каналы

API-ключи

  1. Открой Google Cloud Console и войди в аккаунт Google.
  2. Создай проект: выбор проекта вверху, затем «Новый проект».
  3. «APIs & Services» → «Library», найди «YouTube Data API v3» и нажми «Enable».
  4. «Credentials» → «Create credentials» → «API key».
  5. Скопируй ключ (он начинается с AIza) и вставь сюда. Лучше ограничить его: «Restrict key» → только YouTube Data API v3.
Бесплатной квоты 10 000 единиц в день хватает: проверка канала стоит 1 единицу.
Ключи хранятся только в этом браузере и не блокируются. В резервную копию не попадают. Для каждого канала можно выбрать свой ключ.
